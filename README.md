# Reproducible Data Wrangling and String Parsing Pipeline

## Project Overview
This project implements a reproducible data wrangling and string parsing pipeline using Python and Pandas.

## Dataset
The project uses embedded sample CSV and JSON customer datasets containing inconsistent names, email addresses, phone numbers, dates, currencies, and categorical values.

## Operations Implemented
1. CSV and JSON data loading.
2. Data inspection and profiling.
3. Data cleaning and standardization.
4. Email validation using regular expressions.
5. Phone number cleaning and validation.
6. Date parsing and standardization.
7. Currency string parsing and numeric conversion.
8. Missing value handling.
9. Duplicate detection and removal.
10. Feature engineering and string extraction.
11. Data quality reporting.
12. Category-wise and city-wise analysis.
13. Data visualization.
14. Exporting cleaned datasets into CSV and Excel formats.

## Technologies Used
- Python
- Pandas
- NumPy
- Regular Expressions
- Matplotlib
- Google Colab

## Output Files
- cleaned_customer_data.csv
- cleaned_customer_data.xlsx
- data_quality_report.csv
- category_analysis.png
- city_analysis.png

## How to Run
1. Open the notebook in Google Colab.
2. Run all cells sequentially.
3. Review the cleaned dataset, reports, and visualizations.

## Conclusion
Successfully developed a reproducible data cleaning and transformation pipeline that combines CSV and JSON data, standardizes inconsistent records, validates strings, performs data quality checks, and generates analytical outputs.
